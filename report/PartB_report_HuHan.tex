\subsection*{(b) Learning Rate Comparison Table}

Pneumonia is positive (label 1); the prediction threshold is 0.5. $TP,TN,FP,FN$ denote true positives, true negatives, false positives and false negatives; $N=TP+TN+FP+FN$.
\[
\begin{aligned}
\mathrm{Accuracy} &= \frac{TP+TN}{N}, &
\mathrm{Error} &= 1-\mathrm{Accuracy},\\
\mathrm{Sensitivity} &= \frac{TP}{TP+FN}, &
\mathrm{Specificity} &= \frac{TN}{TN+FP}.
\end{aligned}
\]
Validation loss is binary cross-entropy, with true label $y_i$ and predicted pneumonia probability $p_i$:
\[
\mathcal{L}_{\mathrm{val}}=-\frac{1}{N}\sum_{i=1}^{N}
\bigl[y_i\log p_i+(1-y_i)\log(1-p_i)\bigr].
\]
Each row reports the minimum-error checkpoint (ties: lower loss, then earlier epoch). Error, sensitivity and specificity are percentages.

Parameters include all trainable weights and biases. FLOPs measure convolutional and fully connected computation per $1\times64\times64$ image, counting each multiply--accumulate as two operations.

\textbf{AlexNet-like:} Its $5\times5$ kernels provide larger local receptive fields. The fully connected head contributes to the highest parameter count, and the model has the highest FLOPs and lowest test accuracy and specificity.

\textbf{VGG-like:} Stacked $3\times3$ convolutions add nonlinear transformations, and global average pooling keeps the classifier compact. It achieves the highest accuracy and specificity with the fewest parameters and FLOPs. Global pooling trades spatial detail for compactness; the model produces 69 false positives.

\textbf{ResNet-like:} Residual shortcuts provide direct gradient paths that can ease optimisation. The model detects all 390 pneumonia cases and produces 76 false positives. VGG offers higher accuracy and specificity at lower computational cost.
